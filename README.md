# AttendEase - College Attendance Management System

AttendEase is a dynamic QR-code and face-verification based college attendance management system.

## Project Overview

- **frontend/**: React + Vite + Tailwind CSS frontend application.
- **backend/**: Python Flask backend with SQLAlchemy, JWT, dynamic QR generation (3-second expiration), and face verification module.
- **database/**: Database configuration, migrations, and documentation (SQLite for dev, PostgreSQL ready).
- **docs/**: Architectural designs and attendance flow documentation.
